# פריסת הכלי לענן — כדי שאנשים יוכלו להתחבר ולנסות

הכלי כבר **מוכן לפריסה**: יש בו שרת production (gunicorn) וכל קובצי ההגדרה.
נשארה רק פעולה אחת שדורשת אותך — פתיחת חשבון חינמי בספק הענן ולחיצה על "פרוס".
להלן הדרך הפשוטה ביותר (Render — חינם, ללא כרטיס אשראי, בלי שורת פקודה).

---

## אפשרות א' (מומלץ) — Render, פריסה בלחיצה

1. היכנס ל־https://render.com והירשם עם חשבון הגיטהאב שלך (**Sign up with GitHub**).
2. אשר ל־Render גישה למאגר **`Maoro97/MCP`**.
3. בלוח הבקרה לחץ **New +** → **Blueprint**.
4. בחר את המאגר `Maoro97/MCP` ואת הענף `claude/priority-file-loader-tool-49nxln`
   (או `main`, לאחר שתמזג לשם).
5. Render יזהה אוטומטית את הקובץ `render.yaml` שבשורש המאגר ויציג שירות בשם
   **priority-file-loader**. לחץ **Apply / Deploy**.
6. אחרי 2–4 דקות תתקבל כתובת ציבורית מהצורה:
   `https://priority-file-loader.onrender.com`
   זו הכתובת שתשתף עם אחרים — הם ייכנסו אליה מהדפדפן וינסו את המערכת.

**שים לב (תוכנית חינם):** אחרי כ־15 דקות ללא שימוש השרת "נרדם", והכניסה הבאה
עשויה לקחת 30–50 שניות עד שהוא מתעורר. זה תקין לניסיון/הדגמה.

**עדכונים אוטומטיים:** בזכות `autoDeploy: true`, כל דחיפה של קוד חדש לענף
המחובר תגרום ל־Render לפרוס מחדש אוטומטית.

---

## אפשרות ב' — כל ספק שתומך ב־Docker (Fly.io / Google Cloud Run / Railway)

בשורש המאגר יש `Dockerfile` מוכן. בנייה והרצה מקומית לבדיקה:

```bash
docker build -t priority-file-loader .
docker run -p 8000:8000 priority-file-loader
# ואז בדפדפן: http://localhost:8000
```

בענן — כל ספק Docker יבנה את התמונה ויריץ אותה; הכלי מאזין על הפורט שבמשתנה
הסביבה `PORT` (ברירת מחדל 8000).

## הרצה מקומית (למחשב שלך בלבד, ללא ענן)

```bash
cd file-loader
pip install -r requirements.txt
python webapp.py
# ואז בדפדפן: http://127.0.0.1:5000
```

## הערות חשובות

- **פרטיות ואבטחה:** כתובת ציבורית פתוחה לכל מי שמכיר אותה. הכלי מעבד נתונים
  עסקיים (לקוחות/ספקים/תנועות יומן, ח.פ, סכומים). להדגמה מומלץ להשתמש בנתוני
  דוגמה, ולא בנתוני לקוח אמיתיים, אלא אם תוסיף שכבת הזדהות (סיסמה, ראה למטה).
- **מסך התחברות (סיסמה):** לאפליקציה יש מסך התחברות מובנה. ב-Render:
  **Environment → Environment Variables**, הוסף `APP_PASSWORD` (הסיסמה),
  ואופציונלית `APP_USERNAME` (ברירת מחדל `admin`) ו-`SECRET_KEY` (מחרוזת אקראית
  לחתימת ה-cookie). ללא `APP_PASSWORD` האפליקציה פתוחה. יציאה: קישור **🚪 יציאה**
  בראש הדף.
- **שערי בנק ישראל:** בענן יש גישה לאינטרנט, כך ששליפת שערי המט"ח (BoI) תעבוד —
  בשונה מסביבת הפיתוח המבודדת.
- **מצב־ריצה בזיכרון:** השירות רץ ב־worker יחיד עם מספר threads, כדי לשמור על
  מצב הריצה (RUNS) עקבי בין הבקשות. קבצים שנוצרים נשמרים זמנית ונמחקים בהפעלה
  מחדש — זה תקין לשימוש בהדגמה.
